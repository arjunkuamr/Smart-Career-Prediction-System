# 🚀 CareerVision AI — Smart Career Prediction System

An AI-powered career guidance system built with **Streamlit + Python** that predicts the best career paths from a user's course, skills and interests, and generates a personalized learning roadmap with downloadable PDF report.

## ✨ Features
- 🎯 **AI Career Prediction** — Top-3 careers with match %, ranked by skill / interest / course fit
- 🗺️ **Personalized Roadmap** — step-by-step plan, tools, certifications, project ideas, interview prep
- 📊 **Interactive Dashboard** — Plotly bar chart + radar profile-fit chart
- 🧩 **Skill Gap Analysis** — shows exactly what to learn next
- 🔥 **Trending Careers** — demand vs salary scatter
- 🤖 **AI Chatbot Assistant**
- ⬇️ **Download Roadmap as PDF**
- 🌌 Futuristic dark theme with glassmorphism cards

## 🧩 Tech Stack
Python · Streamlit · Pandas · NumPy · Plotly · Matplotlib · FPDF2

## ▶️ Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ☁️ Deploy on Streamlit Cloud
1. Push this folder to a public GitHub repo.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. New app → pick repo → main file `app.py` → Deploy.
